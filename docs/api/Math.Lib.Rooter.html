Remarks

Finaliza cuando el cambio entre aproximaciones es como máximo el 0.1 % del resultado. La forma (resultado + entrada / resultado) / 2 evita elevar el resultado al cuadrado.

Exceptions

ArgumentOutOfRangeException

La entrada es cero, negativa, NaN o infinita. El mensaje es: El valor ingresado es invalido, solo se puede ingresar números positivos.
